ما هي ضاد؟

ضاد لغة برمجة عربية وبيئة تطوير تهدف إلى تمكين المستخدم من تعلم البرمجة وبناء المشاريع باستخدام مفاهيم وأوامر عربية واضحة.

تجمع ضاد بين لغة البرمجة وبيئة تشغيل ومكتبات مخصصة، مع تركيز خاص على تطوير الويب والتطبيقات التفاعلية.

اطبع("مرحبًا بالعالم")

ما هي ضاد؟

ما هي اللغة؟

ضاد هي لغة برمجة عربية حديثة صُممت لتوفير طريقة واضحة وسهلة لكتابة البرامج باللغة العربية.

تهدف ضاد إلى جعل البرمجة أقرب إلى المطور العربي، من خلال استخدام الكلمات والمفاهيم العربية في كتابة الكود، مع توفير بنية حديثة تدعم بناء تطبيقات الويب والمشاريع البرمجية المختلفة.

ضاد ليست مجرد ترجمة لأوامر لغة أخرى، بل تمتلك بنية لغوية ونظامًا خاصًا بها، وتعمل من خلال محرك ضاد المسؤول عن تحليل الكود وتنفيذه.

وظيفة اللغة

تُستخدم ضاد لكتابة البرامج والتطبيقات بطريقة عربية واضحة، مع التركيز على تطوير تطبيقات الويب والواجهات التفاعلية.

توفر ضاد مجموعة من الأدوات والمكتبات التي تساعد المطور على بناء المشاريع، ومن أبرزها:

  • مكتبة ويب لبناء التطبيقات والتعامل مع عناصر الصفحة والتفاعل معها.
  • مكتبة تصميم لإنشاء وتنسيق واجهات المستخدم.
  • مكتبة قوائم للتعامل مع البيانات والقوائم.
  • مكتبة رياضيات لتنفيذ العمليات والحسابات الرياضية.
  • مكتبة نصوص لمعالجة النصوص.
  • نظام حالة داخل مكتبة ويب لإدارة البيانات التفاعلية.

وتهدف هذه الأدوات إلى تمكين المطور من الانتقال من كتابة الكود إلى بناء تطبيق عملي دون الحاجة إلى معرفة عدد كبير من اللغات المختلفة.

رؤية ضاد

رؤية ضاد هي بناء بيئة برمجية عربية متكاملة تجعل اللغة العربية خيارًا حقيقيًا في عالم البرمجة، وليس مجرد وسيلة تعليمية.

نسعى إلى تطوير لغة واضحة وقوية، وأدوات مناسبة للمطور العربي، وبيئة تساعد على التعلم والتجربة وبناء المشاريع الحقيقية.

كما تهدف ضاد إلى تكوين مجتمع عربي يشارك في تطوير اللغة، ويقترح التحسينات، وينشئ المكتبات والمشاريع، ويساهم في بناء مستقبل برمجي عربي أكثر حضورًا واستقلالًا.

ضاد مشروع مفتوح للتطوير، ورؤيتها أن تصبح البرمجة باللغة العربية أكثر سهولة وانتشارًا، مع الحفاظ على القوة والمرونة التي يحتاجها المطور لبناء مشاريع حقيقية.

دورة ضاد التعليمية

        
100 درس تفاعلي متتالٍ ومنطقي للانتقال من الصفر إلى الاحتراف بلغة ضاد: المتغيرات والدوال، التحكم في التدفق، هياكل البيانات، معالجة الأخطاء والبرمجة غير المتزامنة، الدوال المتقدمة، وحدات النظام (رياضيات، نصوص، قوائم، JSON)، الألوان والتصميم الاحترافي (مرن وشبكي وحركة وتجاوب)، بناء صفحات وتطبيقات ويب كاملة بوحدات متجر وموجه ومكوّنات، خوارزميات وتمارين رياضية وألعاب مصغّرة وجودة كود، وصولًا إلى مشروعَي تخرج ختاميين كبيرين. كل درس يحتوي شرحًا وسؤال اختيار من متعدد وتمرين كتابة كود يُتحقّق منه تلقائيًا بعد تشغيله. كل الكلمات والأمثلة بالعربية بالكامل، بلا تعقيد.

      


      
الأساسيات


      

        
١الطباعة والتعليقات

        
الأمر اطبع() يعرض قيمة أو أكثر على الشاشة، ويمكن تمرير عدة قيم مفصولة بفواصل فتُطبع بمسافة بينها.

        
التعليق سطر يتجاهله المحرّك تمامًا، ويُستخدم لشرح الكود. يبدأ التعليق بعلامة # أو //.

        
# هذا تعليق، والمحرّك يتجاهله تمامًا
اطبع("مرحبًا بالعالم!")
اطبع("أهلاً بك في لغة ضاد")
اطبع("يمكن طباعة أكثر من قيمة معًا:", 1, 2, 3)

        
        

          
سؤال سريع: ما الذي يفعله السطر الذي يبدأ بـ #؟

          

            
            
            
          

          

        

      


      

        
٢المتغيرات والثوابت

        
الكلمة خلي تُنشئ متغيرًا يمكن تغيير قيمته لاحقًا.

        
الكلمة ثابت تُنشئ قيمة لا يمكن تغييرها بعد تعريفها؛ محاولة تغييرها تُسبب خطأً.

        
خلي الاسم = "جوري"
خلي العمر = 20
ثابت اسم_التطبيق = "ضاد"

اطبع("الاسم:", الاسم)
اطبع("العمر:", العمر)
اطبع("التطبيق:", اسم_التطبيق)

العمر = العمر + 1
اطبع("العمر بعد عيد الميلاد:", العمر)

        
        

          
سؤال سريع: ماذا يحدث إذا حاولت تغيير قيمة عُرّفت بـ ثابت؟

          

            
            
            
          

          

        

      


      

        
٣أنواع البيانات

        
لضاد أنواع أساسية: رقم، نص، منطقي (صحيح/خطأ)، فارغ (لا قيمة)، إضافة إلى قائمة وقاموس ودالة ووحدة.

        
الدالة نوع() تُرجع اسم نوع أي قيمة، وهي مفيدة جدًا أثناء التجربة والتصحيح.

        
خلي عدد = 10
خلي كسر = 3.5
خلي جملة = "ضاد"
خلي حالة = صحيح
خلي لاشيء_بعد = فارغ
خلي عناصر = [1, 2, 3]
خلي بيانات = {الاسم: "جوري"}

اطبع("نوع عدد:", نوع(عدد))
اطبع("نوع كسر:", نوع(كسر))
اطبع("نوع جملة:", نوع(جملة))
اطبع("نوع حالة:", نوع(حالة))
اطبع("نوع لاشيء_بعد:", نوع(لاشيء_بعد))
اطبع("نوع عناصر:", نوع(عناصر))
اطبع("نوع بيانات:", نوع(بيانات))

        
        

          
سؤال سريع: ما القيمة التي يُعبَّر عنها بالكلمة المحجوزة فارغ؟

          

            
            
            
          

          

        

      


      

        
٤النصوص ومعالجتها

        
يمكن دمج نصين برمز +، ومعرفة عدد أحرف أي نص بالدالة طول().

        
وحدة نصوص تضيف أدوات جاهزة مثل كبير() وصغير() وقطع() واستبدل() وتقسيم().

        
استورد نصوص

خلي الاسم = "جوري"
خلي التحية = "مرحبًا يا " + الاسم
اطبع(التحية)
اطبع("عدد أحرف الاسم:", طول(الاسم))

اطبع("بحروف كبيرة:", نصوص.كبير("dhad"))
اطبع("قطعة من النص:", نصوص.قطع("البرمجة بالعربية", 0, 7))
اطبع("استبدال:", نصوص.استبدل("أحب البرمجة", "أحب", "أتقن"))
اطبع("تقسيم:", نصوص.تقسيم("تفاح,موز,عنب", ","))

        
        

          
سؤال سريع: أي وحدة تحتوي على دوال مثل كبير() وصغير() واستبدل()؟

          

            
            
            
          

          

        

      


      

        
٥العمليات الحسابية والمنطقية

        
العمليات الحسابية: + - * / % (باقي القسمة)، والمقارنة: == != > < >= <=.

        
العمليات المنطقية: و (and) و أو (or) و ليس (not)، وتُستخدم لدمج أو نفي الشروط.

        
خلي أ = 7
خلي ب = 2

اطبع("جمع:", أ + ب)
اطبع("طرح:", أ - ب)
اطبع("ضرب:", أ * ب)
اطبع("قسمة:", أ / ب)
اطبع("باقي القسمة:", أ % ب)

خلي بالغ = صحيح
خلي لديه_إذن = خطأ
اطبع("بالغ و لديه إذن:", بالغ و لديه_إذن)
اطبع("بالغ أو لديه إذن:", بالغ أو لديه_إذن)
اطبع("ليس بالغ:", ليس بالغ)
اطبع("أ أكبر من ب:", أ > ب)

        
        

          
سؤال سريع: ما ناتج 7 % 2 في ضاد؟

          

            
            
            
          

          

        

      


      
التحكم في التدفق


      

        
٦الشروط: إذا ووإلا

        
إذا تُنفّذ جزءًا من الكود فقط عند تحقق شرط، وتضيف وإلا لتنفيذ بديل إن لم يتحقق.

        
يمكن ربط عدة شروط متتالية بكتابة وإلا إذا بين إذا الأولى و وإلا الأخيرة.

        
خلي العمر = 20

إذا (العمر >= 18) {
    اطبع("بالغ")
} وإلا {
    اطبع("قاصر")
}

خلي الدرجة = 75
إذا (الدرجة >= 90) {
    اطبع("ممتاز")
} وإلا إذا (الدرجة >= 75) {
    اطبع("جيد جدًا")
} وإلا إذا (الدرجة >= 60) {
    اطبع("جيد")
} وإلا {
    اطبع("يحتاج مراجعة")
}

        
        

          
سؤال سريع: كيف تربط أكثر من شرط متتالٍ في ضاد؟

          

            
            
            
          

          

        

      


      

        
٧حلقة العدّ: لكل...من...إلى

        
لكل متغير من بداية إلى نهاية تكرّر تنفيذ جزء من الكود، وتُعطي المتغير كل قيمة من البداية إلى النهاية بالترتيب.

        
يمكن استخدام هذه الحلقة لعدّ تصاعدي أو مع أي عمليات حسابية داخل جسم الحلقة.

        
لكل رقم من 1 إلى 5 {
    اطبع("الرقم:", رقم)
}

خلي المجموع = 0
لكل رقم من 1 إلى 10 {
    المجموع = المجموع + رقم
}
اطبع("مجموع الأرقام من 1 إلى 10:", المجموع)

        
        

          
سؤال سريع: كم مرة سيُطبع الرقم في: لكل رقم من 1 إلى 3 { اطبع(رقم) }؟

          

            
            
            
          

          

        

      


      

        
٨حلقة الشرط: طالما

        
طالما تكرّر تنفيذ الكود ما دام الشرط صحيحًا، وتتوقف تلقائيًا حين يصبح خاطئًا.

        
يجب تحديث المتغير المستخدم في الشرط داخل الحلقة، وإلا استمرت الحلقة إلى ما لا نهاية.

        
خلي عداد = 1
طالما (عداد <= 3) {
    اطبع("محاولة رقم", عداد)
    عداد = عداد + 1
}

خلي رصيد = 100
طالما (رصيد > 0) {
    رصيد = رصيد - 30
    اطبع("الرصيد المتبقي:", رصيد)
}

        
        

          
سؤال سريع: ماذا يحدث إذا نسيت تحديث متغير الشرط داخل طالما؟

          

            
            
            
          

          

        

      


      

        
٩التحكم بالحلقات: توقف واستمر

        
توقف تُنهي الحلقة الحالية فورًا وتخرج منها بالكامل.

        
استمر تتخطّى بقية جسم الحلقة في هذه الدورة فقط، وتنتقل مباشرة للدورة التالية.

        
لكل رقم من 1 إلى 10 {
    إذا (رقم == 5) {
        توقف
    }
    اطبع("قبل التوقف:", رقم)
}

لكل رقم من 1 إلى 6 {
    إذا (رقم % 2 == 0) {
        استمر
    }
    اطبع("رقم فردي:", رقم)
}

        
        

          
سؤال سريع: ما الفرق بين توقف واستمر؟

          

            
            
            
          

          

        

      


      
الدوال والوحدات


      

        
١٠الدوال: تعريف واستدعاء

        
الدالة قطعة كود مُعرّفة بكلمة دالة يمكن استدعاؤها عدة مرات بقيم مختلفة تُسمى معاملات (وسائط).

        
تكتب اسم الدالة يليه قوسان يحتويان المعاملات، ثم جسم الدالة بين قوسين معقوفين.

        
دالة رحب(بالاسم) {
    اطبع("أهلاً", بالاسم)
}
رحب("جوري")
رحب("جوري")

دالة اجمع(أ, ب) {
    إرجع أ + ب
}
اطبع("الناتج:", اجمع(4, 6))

        
        

          
سؤال سريع: ما الكلمة المستخدمة لتعريف دالة في ضاد؟

          

            
            
            
          

          

        

      


      

        
١١القيمة المُرجعة وتركيب الدوال

        
إرجع تُنهي تنفيذ الدالة فورًا وتُعيد قيمة إلى مكان الاستدعاء؛ يمكن استخدام هذه القيمة مباشرة في تعبير آخر.

        
يمكن لدالة أن تستدعي دالة أخرى داخل جسمها، وهذا يُسمى تركيب الدوال، ويساعد على تقسيم المسائل الكبيرة إلى أجزاء صغيرة.

        
دالة مربع(س) {
    إرجع س * س
}

دالة مجموع_المربعات(أ, ب) {
    إرجع مربع(أ) + مربع(ب)
}

اطبع("مربع 5:", مربع(5))
اطبع("مجموع مربعي 3 و 4:", مجموع_المربعات(3, 4))

دالة تصنيف_العمر(عمر) {
    إذا (عمر < 13) { إرجع "طفل" }
    إذا (عمر < 18) { إرجع "مراهق" }
    إرجع "بالغ"

٢٣بناء عناصر HTML بضاد
