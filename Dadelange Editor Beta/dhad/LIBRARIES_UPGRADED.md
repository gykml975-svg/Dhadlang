# تطوير المكتبات الأساسية في ضاد

تم تطوير أربع مكتبات داخل `app/src/main/assets/dhad.browser.js`:

- **ويب 1.1.0**: استماع قابل للإزالة، قياس العناصر، تمرير وتركيز، إظهار/إخفاء، ResizeObserver، IntersectionObserver، حفظ/استرجاع كائنات، Clipboard، requestAnimationFrame، وطلبات JSON مع إعادة المحاولة.
- **تصميم 1.1.0**: أدوات الشبكات والمرونة والطباعة والمسافات والحدود والظلال والحركة والألوان، شبكات متجاوبة، بطاقات وصور وأزرار متقدمة، دعم الوضع الداكن.
- **قوائم**: بحث، بعض، كل، فريد، تسطيح، تجميع، دمج، تكرار، مدى، مجموع، متوسط، أصغر، أكبر، عداد، مجموعات، إزاحة، وفرز حسب مفتاح.
- **رياضيات**: الدوال المثلثية العكسية والزائدية، الأسس واللوغاريتمات، الإشارة والجذر التكعيبي والوتر، الحد والاستيفاء وتحويل النطاق، العامل والتباديل والتوافيق، القاسم والمضاعف المشترك، والعشوائية العشرية والصحيحة.

ملاحظة: تم الحفاظ على المكتبات الأصلية والتوافق مع واجهاتها الموجودة، وإضافة الوظائف الجديدة فوقها. تم التحقق من صحة JavaScript نحويًا، كما نجح فحص بنية المشروع والأمثلة الأساسية؛ اختبار الويب الكامل عبر Node يحتاج بيئة DOM لأن مكتبة `ويب` تعتمد على المتصفح.
