# مواصفة لغة ضاد — 1.0

هذه الوثيقة هي المرجع الرسمي المختصر لصياغة اللغة، وتسبق التنفيذ عند إضافة أي ميزة جديدة.

## المبادئ
- اللغة عربية الاتجاه والهوية، وتقبل Unicode مع حماية صريحة من محارف Bidi الخطرة.
- الكلمات المحجوزة والأسماء العربية مسموحة.
- الأرقام البرمجية المقبولة: `0-9` و`٠-٩`.
- القيم الأساسية: رقم، نص، منطقي، لاشيء، قائمة، قاموس، دالة، وحدة.

## البنية
```text
خلي الاسم = "ضاد"
ثابت الإصدار = 1
إذا (الاسم == "ضاد") { اطبع(الاسم) }
دالة جمع(أ, ب) { إرجع أ + ب }
غير_متزامن دالة تحميل() { إرجع لاشيء }
استورد رياضيات
```

## الوحدات
`استورد اسم` يستورد وحدة، و`استورد اسم باسم لقب` ينشئ اسمًا مستعارًا. الوحدات للقراءة فقط ما لم تنشئها اللغة داخليًا.

## الأخطاء
كل خطأ قابل للتطبيع إلى `DhadError` ويحمل: النوع، الرمز، الرسالة، السطر، العمود، الطول، النص، الاقتراح، المصدر وسلسلة الاستدعاء عند توفرها.

## Async
`غير_متزامن` يعلن دالة غير متزامنة، و`انتظر` ينتظر Promise/قيمة قابلة للانتظار. واجهات المتصفح غير متاحة خارج بيئة المتصفح، وتُرجع خطأ تنفيذ محليًا واضحًا.

## الموارد
الـIDE يفرض حدودًا على حجم الملف وعدد الملفات والحجم الإجمالي للمشروع، ويجب على أي runtime إنتاجي إضافة حدود للتنفيذ والاستدعاء والنتيجة قبل تشغيل كود غير موثوق.

## الألوان وتنسيق الواجهات

توفّر ضاد وحدة `ألوان` لتوحيد التعامل مع الألوان داخل المشاريع، وتدعم أسماء عربية شائعة، وقيم CSS/Hex.

```text
استورد ألوان

خلي الأساسي = ألوان.أخضر
خلي الشفاف = ألوان.شفافية("#176B57", 0.7)
خلي ممزوج = ألوان.خلط("#176B57", "#FFFFFF", 0.25)
خلي فاتح = ألوان.تفتيح("#176B57", 0.2)
خلي داكن = ألوان.تغميق("#176B57", 0.2)
خلي تدرج = ألوان.تدرج_خطي("#176B57", "#2FAF8A")
```

### تنسيق العناصر مباشرة

عند استخدام Markup يمكن تمرير خصائص تنسيق عربية مباشرة:

```text
<بطاقة لون="#FFFFFF" خلفية="#176B57" حواف="16px" ظل="0 8px 30px rgba(0,0,0,.12)">
  <نص لون="أبيض" حجم_الخط="20px">مرحبًا</نص>
</بطاقة>
```

ويمكن تمرير كائن نمط إلى مكونات `تصميم`:

```text
استورد تصميم

خلي بطاقة_رئيسية = تصميم.بطاقة(
  "العنوان",
  "المحتوى",
  "default",
  {لون: ألوان.أبيض, خلفية: ألوان.أخضر, تدوير: "16px"}
)
```

### السمات Themes

```text
استورد تصميم

خلي سمة_ضاد = تصميم.سمة({
  أساسي: "#176B57",
  ثانوي: "#2FAF8A",
  سطح: "#FFFFFF",
  نص: "#17202A"
})
```

يمكن إدخال ناتج السمة في ورقة CSS أو عنصر `نمط`، بينما `تصميم.نظام` يوفّر اختصارًا لإعداد متغيرات الهوية الأساسية.
