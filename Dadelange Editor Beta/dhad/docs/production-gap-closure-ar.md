# إغلاق فجوات Production

تمت إضافة حزمة إغلاق فجوات عملية داخل المشروع:

- `examples/موقع_متجر.ضاد`: موقع متجر كامل مكتوب بلغة ضاد وقابل للنسخ إلى المحرر.
- `tests/production.test.js`: فحوصات آلية للـmanifest، R8، signing، WebView hardening، التشخيص، ووجود مثال الويب وتشغيله.
- `ci/run_android_instrumentation.sh`: إنشاء وتشغيل Android Emulator عند عدم وجود جهاز متصل ثم تنفيذ اختبارات Instrumentation.
- `ProductionDiagnostics.java`: نقطة ربط لتقارير الأعطال والأحداث دون تسجيل كود المستخدم أو محتوى ملفاته.
- Adaptive Icon للإصدارات الحديثة.

## ما يحتاج إعدادًا خارج المستودع

1. وضع ملف keystore في Secrets الخاصة بـCodemagic وتعيين المتغيرات الأربعة المطلوبة.
2. اختيار مزود Crash/ANR معتمد إذا كان الإبلاغ الخارجي مطلوبًا، ثم تمرير Reporter إلى `ProductionDiagnostics` وفق سياسة الخصوصية.
3. نشر سياسة الخصوصية على عنوان HTTPS عام وتحديث بيانات Google Play النهائية.
4. تنفيذ اختبار TalkBack يدوي على جهاز حقيقي.
5. تنفيذ اختبار أمني خارجي قبل الإطلاق التجاري الحساس.

لا يحتوي المثال على مفاتيح API أو أسرار، ولا يعتمد على بيانات مستخدم حقيقية.
