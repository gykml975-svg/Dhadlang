# إدارة المشاريع والملفات

يدعم IDE الآن:
- إنشاء/تبديل/إعادة تسمية/حذف المشاريع.
- إنشاء وتبديل الملفات.
- Autosave سريع بعد الكتابة.
- حفظ مسودة استرداد للجلسة السابقة.
- تخزين صغير في localStorage وتخزين كبير في IndexedDB.
- تصدير واستيراد المشروع بصيغة `dhad-project.json`.
- حد 500 ملف للمشروع، و120 MiB إجماليًا، و55 MiB للملف.
- الحفاظ على الملف الرئيسي عند إنشاء المشروع.
